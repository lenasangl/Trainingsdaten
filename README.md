# Trainingsdaten

Bei dieser Aufgabe war es das Ziel, ein Programm zu schreiben, das die Datei *TrainingRecords.txt* einliest und die Laufdaten von Frau Hofer übersichtlich am Bildschirm ausgibt. Jede Zeile steht für eine Woche und enthält zuerst die Anzahl der Läufe und danach jeweils Distanz (km) und Zeit (min). Für jede Woche sowie für alle Wochen zusammen sollten die **gesamte Distanz**, die **durchschnittliche Distanz pro Lauf** und die **durchschnittliche Geschwindigkeit in min/km** nur mit `int` berechnet und auf **eine Kommastelle gerundet** ausgegeben werden. Wochen ohne Läufe sind mit einer 0 am Zeilenanfang gekennzeichnet; es werden nur Läufe mit mindestens 1 km berücksichtigt.
